# Ashwath Nivas personal site

Plain HTML, CSS and a little JS. Hosted on GitHub Pages.

## Things to remember
- **Search visibility:** every page has `<meta name="robots" content="noindex, follow" />` on purpose.
  When the site is ready to be found (about Jan 2027), delete that line from all five HTML files.
- **New post:** copy an `.entry` block in `writing.html` (and the top three in `index.html`), keep newest first.
- **Now page:** edit `now.html` and bump "Last updated".
- **Theme:** saved in `localStorage` under the key `theme`.
- **Analytics:** GA4 `G-P44QE1404M` is in the `<head>` of every page.
